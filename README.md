## Описание

Этот проект содержит реализации классических структур данных на языке C++.  
Каждая структура представлена в отдельном файле или заголовочном модуле.  
Проект может быть полезен для:

- изучения принципов работы структур данных,
- подготовки к собеседованиям,
- использования в качестве основы для более сложных проектов.

## Реализованные структуры

| Структура         | Файл(ы)                  | Описание |
|------------------|--------------------------|-----------|
| Динамический массив | `dynamic_array.h` / `.cpp` | Шаблонный динамический массив с автоматическим расширением |
| Связный список    | `linked_list.h` / `.cpp`  | Односвязный список с базовыми операциями |
| Двусвязный список | `doubly_linked_list.h`    | Список с возможностью обхода в обе стороны |
| Стек              | `stack.h`                 | LIFO-контейнер на основе массива или списка |
| Очередь           | `queue.h`                 | FIFO-контейнер |
| Бинарное дерево поиска | `bst.h`             | Дерево с операциями вставки, удаления, поиска |
| Хеш-таблица       | `hash_table.h`            | Открытая адресация / метод цепочек |
| Куча (приоритетная очередь) | `heap.h`        | Min-heap / Max-heap |
| Граф (списки смежности) | `graph.h`              | Базовые алгоритмы обхода (BFS, DFS) |

*Актуальный список уточняйте в исходных файлах репозитория.*

## Требования

- Компилятор с поддержкой C++11 или новее (g++, clang++, MSVC)
- CMake (рекомендуется) или возможность прямой компиляции
- (Опционально) Google Test для запуска тестов
